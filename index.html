Lead AI Architect since September 2023. Each detail shows how one part of the platform works.

12

AI analyst

It queries databases, builds charts and dashboards, writes and runs notebook and ETL code, and explains why a job failed from its logs. Risky actions wait for a person to approve, and a run can be steered while it works.

  • 100 tools
  • 14 models across Anthropic, OpenAI, xAI and Moonshot
  • MCP server with OAuth
  • 1,200+ automated tests
22

Hybrid retrieval

Vector and full-text search run side by side over pgvector, then the lists are fused by rank and reranked. Scanned PDFs go through OCR in a separate worker. When a step is slow, keyword-only and unranked fallbacks keep answers coming.

Read how it works

32

Iceberg lakehouse

TB-scale, on Spark 4 and DuckDB with a REST catalog. Every statement is authorized for the person running it, masked by policy and audited. Outside engines get scoped credentials; queries run async with resumable Arrow-paged results on pooled session pods.

42

Cost ledger

Every model call reserves budget before it goes out and settles the real cost after. Moving background jobs like log analysis to a lighter model cut that cost about 11x in live evaluations. Prompts are cached, and requests are sorted by complexity to set their token budget.

Read how it works

52

Ontology, lineage, Agent Builder

Ontology Studio keeps a shared model of business entities and how they relate. Column-level lineage traces any column back through SQL, notebooks and ETL to its sources. A no-code Agent Builder lets teams make their own agents.

62

headroom-scaler

A Kubernetes node autoscaler that adds nodes before pods exist. It keeps bin-packed spare room per priority class, provisions ahead of declared demand, and never evicts or binds a pod.

  • plans 5,000 pods on 100 nodes in ~15 ms
  • 130+ tests
  • Lease-based leader election
  • AWS and KWOK providers
